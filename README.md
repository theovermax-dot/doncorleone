# Бот Don Corleone (Vercel, без базы данных)

Меню из сторис (17 пицц), корзина, доставка или самовывоз, заказ уходит в чат ресторана
с кнопками статусов, клиент получает уведомления. База не нужна: корзина лежит в кнопках,
шаги оформления в сообщениях бота, заказы в чате ресторана.

## Развернуть на Vercel
1. Загрузите папку на GitHub (вместе с папками `api` и `photos`).
2. Vercel → Add New → Project → выберите репозиторий → Deploy.
3. Settings → Environment Variables, добавьте:
   - `BOT_TOKEN` — токен из BotFather
   - `WEBHOOK_SECRET` — любая строка из латиницы, цифр, `_` и `-`, например `doncorleone_2026_x7k`
   - `PHONE` — телефон для раздела «Контакты» (необязательно)
4. Deployments → Redeploy.
5. Откройте в браузере один раз: `https://ВАШ-ПРОЕКТ.vercel.app/api/webhook?setup=ВАШ_WEBHOOK_SECRET`
   Должно написать «Готово. Вебхук установлен».
6. Напишите боту `/here` из чата, куда должны приходить заказы (личка менеджера или группа с ботом).
   Бот ответит ID чата.
7. Добавьте этот ID в переменную `ORDERS_CHAT_ID` и снова сделайте Redeploy.

## Что править
- `menu.py`: цены, составы, новые позиции (фото кладите в `photos/`, имя без расширения).
- `bot.py`, блок настроек вверху: адрес, Instagram, способы оплаты.

## Особенности без базы
- Корзина живёт в открытом меню. Если открыть новое меню через /start или /menu, корзина пустая.
- Номер заказа равен номеру сообщения в чате ресторана, поэтому идёт не подряд.
- История заказов хранится только в чате ресторана.

## Локальный запуск (для проверки)
Файл `.env` по образцу `.env.example`, затем `start.bat`.
Если у бота стоит вебхук, локально он не заработает: сначала откройте
`https://api.telegram.org/botТОКЕН/deleteWebhook`.
